# **Cafe Sales Data Cleaning \& Dashboard**



## **Business Problem**



The objective of this project was to take a messy, raw dataset of cafe sales, clean the data, and build an interactive dashboard to provide the business with clear revenue insights.



### **Tools Used**



Microsoft Excel (Data Cleaning, Pivot Tables, Dashboard)



## **Data Cleaning Steps**



1\. Converted raw CSV text into structured columns.

2\. Removed duplicate transaction rows.

3\. Handled missing/error values (filtered out 'UNKNOWN'/'ERROR' rows).



### **Key Insights**



Insert Insight: Coffee generated the highest revenue.

Insert Insight: Most customers paid via Digital Wallet.

Insert Insight: Takeaway was the most popular location.
